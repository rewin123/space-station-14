# наука-консоль
когда: поля консоли анализа и роль сканера нод
Консоль анализа (Analysis Console) — основное устройство ксеноархеолога: показывает
дерево нод артефакта и извлекает очки с открытых нод. Устройство артефакта и
порядок вскрытия — [[наука-вскрытие]], [[наука-артефакты]].

СВЯЗКА
  Консоль должна быть связана с анализатором артефактов (Artifact Analyzer)
  мультитулом: без связи она не видит артефакт. Анализатор сканирует артефакт и
  отправляет данные на консоль.

ПОЛЯ КОНСОЛИ — по каждой ноде
  ID — уникальный идентификатор ноды; сканер нод работает с ним.
  Class (класс) — имя слоя; ноды одного слоя делят один класс.
  Status (статус) — три состояния: Locked — по умолчанию; Active — после первого
  триггера; Unlocked — когда достигнута более глубокая нода, в этом состоянии
  ручные активации предотвращаются.
  Durability (прочность) — сколько ручных активаций осталось.
  Effect (эффект) — что произойдёт при активации или ручном срабатывании.
  Triggers (триггеры) — какие действия нужны, чтобы вскрыть ноду.
  Server (сервер) — выбор исследовательского сервера, куда уйдут извлечённые очки.
  Extract Points (извлечь очки) — снимает очки с нод, открытых после прошлого
  извлечения.

СКАНЕР НОД (Node Scanner)
  Ручное устройство: показывает ID ноды, которая активируется прямо сейчас, и готов
  ли артефакт к срабатыванию. Это минимальный набор для работы в камере у
  артефакта, когда нет прямого доступа к консоли.

ЖЕЛЕЗО И ЕГО ИСТОЧНИК
  Консоль анализа, анализатор и сканер нод печатаются по узлу Basic XenoArcheology
  (Experimental, T1, 5000 очков): [[наука-эксперименты]].
  Пока артефакт не просканирован анализатором, дерево на консоли не появится; очки
  с нод извлекаются только здесь, кнопкой Extract Points.
