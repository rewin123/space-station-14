# словарь-жаргон
когда: Незнакомое слово в чате — AOS, KOS, AA, TC, гринтайд
Экипаж и админы говорят сокращениями. Часть — игровой сленг (звучит в отыгрыше), часть — чисто
OOC. Путать их — самому заговорить внеролево посреди смены.

ИГРОВОЙ ЖАРГОН (можно слышать и произносить в отыгрыше)
  AOS/KOS — arrest/kill on sight: арестовать при встрече / убить на месте без ареста.
  AA — all access, доступ на все двери разом; по умолчанию только у капитана.
  Атмос/Атмосианин — атмосферный техник или спец по атмосфере.
  Заболчен (Bolted) — шлюз сам не сменит состояние; закрытый заболченный горит сплошным красным.
    Emergency Access/EA — режим, который открывает кто угодно без ID, мигающий жёлтый.
  Emag — криптосеквенсер синдиката; «заэмаженный» — взломан им, а не заболчен штатно.
  Борг — киборг-игрок. Braindead/SSD — игрок отключился, но может вернуться в того же перса.
  Бриг/Perma — зона СБ для заключённых (заведует Warden) / пожизненное заключение, обычно
    отдельная зона.
  Cap/CE/CMO/HoP/HoS/QM/RD — капитан / старший инженер / старший врач / глава персонала (его
    кабинет — где выдают/меняют ID) / глава СБ / квартирмейстер / научный директор.
  CentComm — организация Nanotrasen, присматривающая за станцией.
  Crit — без сознания и без движения; здоровье тает, пока не помогут.
  ERT — группа быстрого реагирования от Центкома. Nukie/Newkie/Flukie — ядерный оперативник /
    неопытный в этой роли / провалившая задание команда таких.
  God(s) — IC-имя администратора; иногда так зовут и Центком.
  Greytide/Assistant — пассажир по цвету формы, либо оскорбление про мелкое хулиганство.
  Insuls — изолирующие перчатки (Insulated Gloves), жёлтые, защищают от тока лучше бюджетных.
  Jani/Sci/Sec/Secoff/Salv — уборщик / Science / Security / офицер СБ / утилизатор.
  Mats — материалы: сталь, пластик, пласталь, стекло, серебро, золото.
  Robust — «робастный»: умелый в бою.
  Singulo/Singuloose — сингулярность (бесконечная энергия, очень опасна) / вырвавшаяся из
    удержания, рвёт станцию насквозь.
  Spacing — потеря давления в отсеке.
  Syndie/TC — сотрудник Синдиката любого ранга / телекристалл, валюта его агентов на контрабанду.

ТОЛЬКО ДЛЯ OOC (не произносить в отыгрыше)
  Admeme — событие, устроенное или вызванное админом. AHelp/Bwoink — канал жалоб администрации /
    звук такого обращения. Antag — специально выбранный игрок для внесения хаоса в раунд.
  Ick Ock — восклицание в OOC, когда кто-то раскрыл внутриигровую тайну вне игры.
  LOOC/OOC — локальный и общий внероле-вые каналы; LOOC работает во время раунда, OOC обычно
    только после его конца. LRP/MRP/HRP — уровни отыгрыша сервера: низкий/средний/высокий; HRP
    требует предысторию персонажа и строгого протокола.
  Self-Antag — игрок без роли антагониста, ведущий себя как антагонист без причины; наказуемо.
  Upstream — базовая версия игры, куда «стекают» изменения всех форков.
  Validhunter — игрок, охотящийся на «валидных для убийства», не будучи сам СБ.
