# питание-мониторинг
когда: консоль мониторинга, мультитул по кабелю, цифры по сети
Консоль мониторинга питания (power monitoring computer) — консоль, которая осматривает все
электрические сети станции разом. Инженер использует её, чтобы диагностировать проблему с
питанием и найти её корневую причину, а не гадать. Два раздела: карта станции и статистика
мощности.

КАРТА СТАНЦИИ
Показывает три слоя сразу:
1. Раскладку станции с подсвеченными тремя сетями: зелёной LV, жёлтой MV и оранжевой HV.
2. Все щитки APC, СМЕС и подстанции.
3. Все источники питания, подключённые к станции. Источники показываются даже тогда, когда они
   в данный момент не подключены ни к одной сети, — так и видят «двигатель собран, но не
   подключён».

СТАТИСТИКА МОЩНОСТИ
Ровно три числа:
- суммарная выработка генераторов (total generator output) — то, что генераторы производят
  прямо сейчас, чтобы покрыть спрос сети;
- суммарное потребление из батарей (total battery usage) — сколько сеть снимает с батарей;
  сеть, полностью питаемая генераторами, показывает низкое потребление;
- суммарная нагрузка сети (total network load) — сколько мощности сейчас запрашивает станция.

Идеальная ситуация: выработка совпадает с нагрузкой, а потребление из батарей низкое. По этим
трём числам получается точная картина состояния питания.

ЧЕТЫРЕ ПРОЧТЕНИЯ
- Выработка ниже нагрузки — станция в дефиците мощности.
- Потребление из батарей высокое — станция снимает с батарей, чтобы закрыть разницу.
- Потребление из батарей ноль и при этом выработка ниже нагрузки — активный brownout:
  батареи полностью разряжены, см. [[питание-авария]].
- Выработка выше нагрузки — СМЕС заряжаются, см. [[питание-smes]].

ВКЛАДКИ УСТРОЙСТВ
Есть вкладка для каждой категории устройств станции; вкладка показывает статистику питания
всех устройств этой категории.
Клик по источнику: видно, что именно этот источник питает и сколько мощности отдаёт, плюс
подсвечиваются подключённые к нему устройства.
Клик по СМЕС, подстанции или APC: видны две сети, к которым оно подключено, сколько оно
получает, сколько распределяет, и точный список устройств, которые обмениваются с ним
мощностью. Так находятся «подстанция берёт, но не отдаёт» и «этот APC ни с кем не
обменивается».

МУЛЬТИТУЛ ПО КАБЕЛЮ
Инженер кликает мультитул (multitool) по кабелю и получает шесть чисел. Важно: они относятся
только к той сети напряжений, к которой принадлежит кабель:
- current supply — сколько источник реально отдаёт сейчас;
- current supply from batteries — сколько сеть снимает с батарей;
- theoretical supply — сколько источник мог бы отдать, если бы на него был спрос (теоретический
  максимум);
- ideal consumption — текущий спрос именно на этой линии;
- input storage — ёмкость батарей, которые сейчас заряжаются;
- output storage — ёмкость батарей, которые сейчас разряжаются.

Зелёный LV-кабель, который обслуживает пару-тройку комнат, покажет совсем не те цифры, что
оранжевый HV-кабель, который кормит всю станцию. Поэтому «одна комната питается, а соседняя —
нет» сначала диагностируется сравнением двух соседних линий: на одной полные цифры, на другой
ноль, — разрыв между ними, см. [[питание-провода]].

ЕЩЁ ГДЕ ЧИТАЮТ ЦИФРЫ
Контроллер AME сам показывает два числа: сколько мощности он реально отдаёт сети и каков
теоретический максимум двигателя, см. [[питание-ame]].
